# 기능
1. 뉴스 - 뉴스를 제작하고 업로드 할 수 있습니다.
2. 주식 - 회사의 별점을 정하고 그에 따라 주식의 가격이 변동됩니다. 
3. 카지노 - 돈을 걸고 룰렛을 돌리거나 도박할 수 있습니다.
4. 처벌 - 유저를 강도와 정해진 시간에 맞게 처벌할 수 있습니다.
5. 노선 - 인게임의 버스, 지하철 등의 구조물에 맞게 노선을 설정하고 열람할 수 있습니다.

# 명령어
## 뉴스
- uploadnews(뉴스업로드) : 뉴스의 제목과 내용을 정하고 업로드합니다.
- deletenews(뉴스삭제) : 뉴스 목록에서 자신이 올린 뉴스를 제거합니다.
- checknews(뉴스확인) : 지금까지 나온 뉴스 목록을 확인합니다.
## 주식
- buy(구매) : 주식을 구매합니다. 
- sell(판매) : 주식을 판매합니다.
- setstars(별점) : 주식회사의 별점을 조정합니다.
- checkstats(주식) : 주식회사의 정보를 확인합니다.
- makecompany(상장등록) : 주식회사를 새로 생성합니다.
- setstartmoney(기본돈) : 기본 돈을 설정합니다.
- setmoney(돈설정) : 특정 플레이어의 돈을 설정합니다.
- wealthrank(자산순위) : 서버에서 돈이 가장 많은 플레이어를 확인할 수 있습니다.
## 카지노
- gamble(도박) : 돈을 가지고 도박을 합니다. 기본 확률은 50%이고 실패할 때마다 확률이 올라갑니다.
- roulette(룰렛) : 돈을 가지고 룰렛을 돌립니다. 확률은 완전 랜덤입니다.
## 처벌
- punish(처벌) : 특정 플레이어를 특정 강도(1~4)에 따라 처벌합니다.
- unpunish(처벌해제) : 처벌을 해제합니다.
- punishments.yml 에서 처벌 예외 유저를 정할 수 있습니다.
## 노선
- routes(노선) : 노선(역) 정보를 파일에서 읽어 표시합니다. 역·선 이름으로 검색 가능합니다.
- `resources/routes.json`으로 정보를 관리할 수 있습니다.

|강도|내용|
|-|------------------------|
|1|op 제거|
|2|op 제거 및 모험 모드 고정|
|3|op 제거 및 관전자 모드 고정|
|4|지정된 시간까지 밴|

# 추가 기능
## 엔티티 & 블록 차단
- 건축 서버에서 큰 위협이 되는 테러 블록을 방지할 수 있습니다.
- resources/block_entity.yml 에서 블록이나 엔티티를 추가할 수 있습니다.
## 클리어 엔티티
- clearentity: safe_entity.yml 에 존재하지 않는 모든 엔티티를 죽입니다.
- checksafeentity: safe_entity.yml 에 존재하는 엔티티를 확인합니다.
- addsafeentity: safe_entity.yml 에 엔티티를 추가합니다.
- delsaffeentity: safe_entity.yml 에서 엔티티를 제거합니다.
- OP만 사용할 수 있으며 서버에 렉을 유발하는 기타 엔티티를 처리하는데 효과적입니다.
- 기본적으로 추가되어있는 엔티티는 다음과 같습니다.
    - 갑옷 거치대
    - 블록 디스플레이
    - 아이템 디스플레이
    - 아이템 액자
    - 발광 아이템 액자
    - 플레이어
    - 그림
    - 마네킹

# 다국어 메시지
- `/language` 또는 `/언어`로 한국어·영어 등 표시 언어를 선택합니다.
- `resources/languages/`의 YAML 파일로 메시지를 관리하며, 플레이어별 선택을 저장합니다.
- `/language reload`로 운영 중 수정한 언어 파일을 적용합니다. (기본 OP 권한)
